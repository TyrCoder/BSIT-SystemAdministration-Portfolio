# &#x20;Tyr Technologies — Enterprise Infrastructure Planning

# 

# &#x20;Project Overview

# 

# This project presents the IT infrastructure plan for Tyr Technologies, Inc., a fictional software development startup with 20 employees.

# 

# The project focuses on planning the company's hardware, software, network, security, and system administration requirements before deployment.

# 

# Learning Objectives

# 

# Through this project, I learned how to:

# 

# \* Analyze the IT needs of a small business.

# \* Create hardware, software, and network inventories.

# \* Design a basic enterprise network.

# \* Identify different system administration roles.

# \* Recommend suitable IT infrastructure and security practices.

# \* Create professional technical documentation.

# 

# Company Scenario

# 

# Tyr Technologies, Inc. is a newly established software development and IT solutions company with 20 employees.

# 

# The company has four departments:

# 

# | Department             | Employees |

# | ---------------------- | --------: |

# | Information Technology |         5 |

# | Human Resources        |         4 |

# | Finance                |         5 |

# | Sales                  |         6 |

# |   Total                |        20 |

# 

# The company is starting with no computers, server, network, internet infrastructure, or security policies, so the IT infrastructure needs to be planned from the beginning.

# 

# &#x20;Hardware Inventory Summary

# 

# The planned hardware includes:

# 

# \* 15 Desktop Computers

# \* 5 Laptops

# \* 1 Server

# \* 1 Router

# \* 1 Managed Switch

# \* 2 Network Printers

# \* 3 UPS units

# \* 2 Wireless Access Points

# \* 1 NAS Storage

# \* 2 External Backup Drives

# \* 20 Monitors

# &#x20;Challenges Encountered

# 

# One of the main challenges was planning the network layout and deciding how the different departments and devices should connect. Another challenge was choosing hardware and software that would be enough for the company's current needs without making the infrastructure unnecessarily expensive.
